# Слой routes

Слой маршрутизации. Определяет маршруты и навигацию между страницами приложения. Вынесен в отдельный слой для более простой и централизованной навигации по приложению. Не содержит ничего, кроме описания роутов.

Есть два типа маршрутов:
-- публичные (например "не авторизован", "оштбка 404")
-- приватные (все что требует авторизации)

Пример структуры:
```
├── routes
│   ├── private/
│   ├── public/
│   ├── ...
│   ├── app.routes.ts
│   └── index.ts
```
