# Слой widgets

Независимые UI-блоки, которые могут использоваться на страницах. Обычно не содержат бизнес-логики.

Содержит логику работы конкретного крупного блока. Главное отличие от слоя features — виджет состоит из одной или нескольких feature, а также может включать общий компонент. Виджет обеспечивает связь между features. По сути, виджет — это та же фича, но объединяющая несколько фичей или одну фичу и общий компонент.

Также виджет отвечает за загрузку данных, необходимых для работы своего блока.

Пример структуры:
```
├── widgets/                 # Слой 'widgets' - переиспользуемые компоненты
│   ├── header/
│   │   ├── types/
│   │   │   └── header.interface.ts
│   │   ├── service/
│   │   │   └── header.service.ts
│   │   ├── api/              # выборка данных с бэка, запросы через стор
│   │   │   └── header.api.ts
│   │   ├── index.ts
│   │   └── header.component.ts
│   ├── sidebar/
│   │   ├── types/
│   │   │   └── sidebar.intarface.ts
│   │   ├── service/
│   │   │   └── sidebar.service.ts -- вся логика компонента должна быть вынесена в сервис, сервисов может быть несколько
│   │   ├── api/              # выборка данных с бэка, запросы через стор
│   │   │   └── sidebar.api.ts
│   │   ├── index.ts
│   │   └── sidebar.component.ts -- исполняет описанный выше интерфейс, передает события в сервис, получает и отдает события
│   └── ...
```
