# Слой shared

Общий слой, содержит переиспользуемые компоненты, утилиты, типы, константы и стили. Используется всеми остальными слоями.

Данный слой разбит на несколько своих слоёв:
- ui — переиспользуемые UI-компоненты (кнопки, инпуты и т.д.)
- lib — утилиты, функции, хелперы
- api — общие API-запросы и клиенты
- icons — иконки
- styles — глобальные и общие стили
- i18n — файлы локализации и переводы
- interceptions — перехватчики (например, HTTP-интерцепторы)
