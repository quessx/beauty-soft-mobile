# Генерация API-клиента

Для генерации или обновления API-клиента используйте команду:

```bash
npm run api-client
```

Эта команда скачает OpenAPI-спецификацию и сгенерирует клиентские файлы в папке `src/shared/api`.

**Не используйте `ng generate` или другие команды Angular CLI для генерации API-клиента.**

# Важно: автогенерация

Все файлы в папке api создаются автоматически на основе OpenAPI-спецификации.

**Ручное редактирование любых файлов в папке api запрещено.**

Любые изменения будут перезаписаны при следующей генерации.

> Все изменения в папке api должны вноситься только через генерацию, ручное редактирование файлов запрещено.
