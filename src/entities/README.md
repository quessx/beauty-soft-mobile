# Слой entities

Бизнес-сущности, модели, их логика и взаимодействие между ними.

Это слой сторов: здесь происходит хранение данных приложения. Все данные, поступающие в слой, должны быть преобразованы в модель (DTO).

Пример структуры:
```
├── entities/                # Слой 'entities' - бизнес-сущности и их логика
│   ├── user/                # ngrx
│   │   ├── model/           # NgRx/Service, типы, интерфейсы, стейт
│   │   │   └── user.model.ts -- модель сущности стора (именно класс, не тип)
│   │   ├── types/           # интерфейсы и типы этой сущности
│   │   │   └── user.interface.ts
│   │   ├── api/
│   │   │   ├── user.api.ts -- методы для стора работы с апи
│   │   │   ├── user.get-all.filter.class.ts -- фильтр под определённый запрос
│   │   │   ├── user.by-id.filter.class.ts -- фильтр под определённый запрос
│   │   │   ├── user.store.types.ts -- типы и интерфейсы, относящиеся к данному стору
│   │   ├── index.ts
│   │   └── user.store.ts -- файл стора
│   └── ...
```
